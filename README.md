# 文科生转 AI 路径咨询 Skill

一个面向文科、文商科、艺术类和其他非技术背景用户的多轮职业咨询 Skill。

它不急着告诉你“适合什么岗位”，而是结合毕业或转行时间、真实经历、职业动机、简历、作品集与目标 JD，帮助你判断：

- 现在最现实的 AI 入行切口是什么；
- 过去的经历里，哪些能成为招聘方看得懂的证据；
- 真正缺的是能力，还是证明能力的作品与结果；
- 接下来 30 天，先做什么比继续泛泛学习更有效。

如果你还不准备求职，它也可以先帮助你探索：怎样用 AI 赋能原专业、研究或自媒体，并把探索逐步变成可验证的实践。

当前版本：`v0.2.5`

## 适合谁

- 想进入 AI 行业，但不确定产品、运营、内容、社区、市场、GTM、评测等方向如何选择；
- 有传统行业、内容、品牌、研究或社群经历，不知道如何翻译成 AI 岗位资产；
- 学了很多工具和课程，却仍缺少作品集、项目证据或清晰的投递方向；
- 想先让 AI 进入自己的专业、学业或创作，再判断是否转向 AI 职业；
- 已经有简历、作品集、JD 或录用机会，希望获得更具体的比较与校准。

## 它会怎样与你对话

1. **先分流问题**：判断你是在做 AI 求职决策，还是先探索 AI 与原专业、自媒体的结合。
2. **再补关键背景**：默认每轮只问一个会改变结论的问题，并解释为什么要问。
3. **用证据做判断**：只使用你明确说过或材料直接支持的经历，不自动补写“主导、冷启动、推动、复盘”等动作。
4. **比较三层路径**：给出当前首选、受阻时的备用选择，以及积累一两段经历后的长期方向。
5. **落到下一步**：把建议变成项目、用户反馈、简历证据、投递或访谈动作，而不是一张课程清单。
6. **必要时连接真人**：遇到高度个人化的选择或 is涵 本人的经验边界时，提供 Tara 内的免费真人交流入口。

## 它和常见的转行建议有什么不同

- **不把“文科生”当结论**：专业背景只是输入，真正决定路径的是经历、时间线、岗位认知和已有证明。
- **不默认推荐同一条路**：不会把某个人的“公关 → 运营 → 产品”经历包装成所有人的标准答案。
- **不把团队成果写成个人能力**：严格区分项目目标、本人动作与有证据的结果。
- **不制造技术焦虑**：先判断目标岗位究竟需要什么，再决定是否补技术、业务闭环或作品证据。
- **不一次抛出一份大报告**：通过低压力的多轮对话，让判断随着信息逐步形成。

## 可以这样开始

```text
使用 $ishann-tara-ai-career。我是新闻学硕士，有两段内容运营实习，
不会代码，想做 AI 产品，但不知道现在应该先补什么。
```

```text
使用 $ishann-tara-ai-career。我是中医专业的学生，想用 AI 赋能学业和自媒体，
暂时不确定要不要进入 AI 行业。请先帮我选一个能在两周内验证的小方向。
```

```text
使用 $ishann-tara-ai-career。下面是我的简历和目标 JD，
请帮我判断当前首选岗位、证明缺口，以及未来 30 天最值得完成的一项作品。
```

没有简历或明确目标也可以开始。Skill 会先从一个容易回答的问题切入。

## 安装

### 方式一：使用 Git

```bash
mkdir -p ~/.codex/skills
git clone https://github.com/xHann03/ishann-tara-ai-career.git \
  ~/.codex/skills/ishann-tara-ai-career
```

### 方式二：下载 ZIP

1. 点击仓库右上角的 **Code → Download ZIP**；
2. 解压后将文件夹命名为 `ishann-tara-ai-career`；
3. 放入 `~/.codex/skills/`；
4. 重启 Codex。

安装后，可以直接描述自己的问题，也可以明确调用：

```text
使用 $ishann-tara-ai-career，帮我判断最现实的 AI 入行路径。
```

## 使用边界

- 不提供算法工程师的系统学习路线；
- 不把模型输出当作实时招聘、薪资或公司信息，涉及新鲜信息时应重新核验；
- 不提供医疗、法律等专业决策，相关内容必须回到权威来源并由人复核；
- 不编造用户经历，也不承诺内推、录用、薪资或真人回复时间；
- 不需要上传完整个人资料库，简历与作品集应按实际咨询需要最小化提供。
