# 消费入口适配

同一套 Skill 核心逻辑只做入口适配，不维护三套诊断逻辑。

## Codex / Claude Code / Workbuddy

- 支持自由描述背景、上传简历/JD/项目、多轮追问和路径对比。
- 先读取材料，再问缺失且会改变结论的问题。
- 完整诊断可使用三层路径、经历翻译、缺口分析、30 天行动和“现在先别做什么”。

## Skill 榜

**标题：**文科生转 AI 路径咨询

**副标题：**输入你的专业和经历，看看你最适合从哪个 AI 岗位切入。

**一句话说明：**不知道该投产品、运营、市场还是内容？不用先填一长串问卷，我们一轮聊一个问题，慢慢把最现实的入口捋出来。

**适合谁：**纯文科、文商科、艺术类和其他非技术背景；找 AI 实习、校招或转行；学了很多 AI 但无法转成求职竞争力的人。

页面保持短，主要动作是“开始聊聊”“关于 is涵”“去 Tara 免费找 is涵”，不要把页面写成长攻略。

## Tara 端内

- 优先复用 Tara 已有背景信息，不重复询问已知专业、经历、兴趣和目标。
- 直接给基于已有背景信息的初步判断，只补问会改变结论的关键问题。
- 用户应明显感受到“同一个 Skill，因为 Tara 更懂我，所以更好用”。
- 触发真人接力时优先使用端内主页或 Chat 深链；在深链尚未配置前展示 Tara ID 942086。
- 真人聊天明确标注免费；展示时区分注册填写的内推码 NPYISF 和端内搜索 is涵的 Tara ID 942086。
