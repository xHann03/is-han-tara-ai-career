# AI 非技术与弱技术岗位地图

这张地图用于路径比较，不是固定岗位目录。岗位名称会变化，判断时优先看工作内容、成功指标和真实交付物。

## 判断岗位，不只看名字

至少回答五个问题：

1. 这个岗位的主要用户或客户是谁？
2. 每周最常做的三类任务是什么？
3. 结果用什么指标或产出来评价？
4. 是否真正接触产品、模型能力、用户反馈或业务决策？
5. 一年后能沉淀什么可迁移资产？

如果岗位只把原工作加上“AI”前缀，但不接触模型能力、真实用户、业务结果或可迁移方法，应谨慎判断其成长性。

## 路径比较维度

内部比较每条路径时，综合以下维度，不必机械展示分数：

- **经验邻近度**：已有经历能否直接迁移。
- **兴趣适配**：喜欢的工作内容，而不是只喜欢岗位名称。
- **30 天可证明性**：短期内能否做出可信作品或成果。
- **进入可达性**：以当前阶段能否获得面试、项目或真实协作机会。
- **技术爬坡匹配**：需要补的技术是否在用户可承受范围。
- **长期选项价值**：第一段经历是否能打开更好的下一步。

当前首选通常不是“最理想的终点”，而是现在最能形成有效证明并打开下一步的入口。

## 常见能力迁移

| 原经历 | 不要只写 | 可翻译为 | 可能对应路径 |
|---|---|---|---|
| 公众号 / 内容运营 | 会写文章 | 用户需求识别、复杂信息转译、选题与分发、数据反馈 | 内容、社区、产品运营、公关、用户侧产品 |
| 社团 / 活动负责人 | 组织过活动 | 项目推进、多方协作、机制设计、供给管理、现场执行 | 社区、运营、增长、项目、创作者业务 |
| 论文 / 研究 | 会查资料 | 问题定义、资料综合、访谈、标准建立、结构化表达 | 评测、研究、产品、行业内容、解决方案 |
| 中文 / 语言 / 翻译 | 会写作、语言好 | 语义辨析、复杂信息转译、语言质量判断、文化语境与表达标准 | 评测、对话体验、内容、国际化、用户研究 |
| 咨询 / 商业分析 | 做过报告 | 场景拆解、客户问题、价值主张、方案表达 | 商业化、解决方案、产品 |
| 教育 / 培训 | 会讲课 | 用户分层、复杂概念解释、课程与反馈闭环 | 内容、社区、客户成功、产品运营 |
| 设计 / 艺术 | 审美好 | 交互表达、原型、视觉叙事、体验判断 | AI 用户体验、对话体验、产品、创意工具 |
| 销售 / 商务拓展 | 会沟通 | 客户洞察、异议处理、需求确认、商业闭环 | 商业化、客户成功、解决方案 |
